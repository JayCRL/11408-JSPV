## 🤝 参与共建与交流

十分欢迎大家参与本仓库的维护和完善！如果你发现了错误，或者有更好的解题思路、知识补充，欢迎通过以下方式参与：

1. **Submit Issue**：提出错别字、知识漏洞、更好的理解方案或参与讨论。
2. **Pull Request (PR)**：
   - Fork 本仓库。
   - 新建分支（如 `feat-new-topic` 或 `fix-typo`）。
   - 提交你的修改并创建 PR。
3. **点个 Star**：如果这个仓库对你的备考或学习有帮助，不妨点一个 ⭐ **Star** 支持一下，这也是我坚持每天更新的最大动力！
